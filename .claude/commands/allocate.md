# allocate

Read CLAUDE.md. Read show first. Record a local allocation only after the operator confirms the device and capacity. This does not activate a customer application.

Run `node scripts/entitlements.mjs allocate` with the required positional arguments shown by the README. Supported flags: code device actor, plus --json.

Mutations need the operator label in --actor. Do not guess missing business facts. Ambiguous matches must be resolved by a code. Nothing sends or changes a remote application.
